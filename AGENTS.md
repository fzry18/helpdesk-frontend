# Project Rules & Guidelines

## Overview
This repository is the frontend for the Helpdesk application built with Next.js, React, Tailwind CSS, and TypeScript.

## antislop
For any UI, copywriting, accessibility, mobile layout, or code comments work, strictly follow the antislop rules and its skills:
- **Core rules & audit checklist**: `skills/antislop/SKILL.md` (Rules R-01 through R-38)
- **UI & Visual Design**: `skills/antislop-ui/SKILL.md`
- **Copywriting & Tone**: `skills/antislop-copywriting/SKILL.md`
- **Human & Accessibility**: `skills/antislop-human/SKILL.md` (WCAG AA contrast, keyboard navigation)
- **Mobile Layout**: `skills/antislop-layoutmobile/SKILL.md` (No horizontal overflow, min 44px tap targets)
- **Code Comments**: `skills/antislop-code/SKILL.md` (Clean, meaningful comments only, no generic AI slop)

Before starting UI work, confirm whether antislop applies:
1. **DURING**: Apply rules directly while building/planning.
2. **AFTER**: Run an audit on existing code and produce a numbered findings list before fixing.
